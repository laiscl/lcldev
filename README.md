# Portfolio - Lais Costa

Portfolio profissional desenvolvido em React + TypeScript para apresentar experiencia, projetos e formas de contato.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Executar localmente

```bash
npm install
npm run dev
```

## Build de producao

```bash
npm run build
npm run preview
```

## Deploy (GitHub Pages)

Este repositório possui workflow para publicar automaticamente no GitHub Pages a cada push na branch `main`.

URL esperada:

`https://laiscl.github.io/lcldev/`

## Estrutura principal

- `src/components`: componentes da interface
- `src/contexts`: contexto de idioma e textos
- `src/pages`: paginas
- `src/index.css`: tokens visuais e estilos globais
